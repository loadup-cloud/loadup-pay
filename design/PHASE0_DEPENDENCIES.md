# 阶段 0 实际依赖清单

核对日期：2026-11-15。范围：Framework、Modules、Pay、Testify 的全部 174 个源码 POM。此清单记录当前工作区的声明，不运行 Maven，不等同于 effective POM、已解析依赖树或最终运行 classpath。

下表为阶段 0 采样快照。后续阶段 1A 的 POM 增量见文末；源码 POM 链接指向当前文件，不表示阶段 0 表格已包含所有后续声明。

## 1 读取规则

- 每行链接到实际 POM；compile/runtime/provided/test 按声明区分，未写 scope 按 Maven 默认 compile 记录。optional 单独标明，它仍是本模块依赖，不能理解为本模块不需要。
- 依赖列保留直接内部和外部依赖，简写为 artifactId；具体 groupId、版本、排除及配置以链接的 POM 为准。profile 内声明用 profile=<id> 标记，不能推断该 profile 已激活。
- 父 POM、dependencyManagement/BOM import、普通 dependency、构建插件/处理器是不同关系。依赖管理不会自动把被管理制品引入 classpath。下表单列 BOM import；完整管理项通过其 POM 查看。
- 父级继承的普通依赖、第三方传递依赖、版本仲裁、平台激活 profile 与插件实际执行不在这份静态表中展开。源码 import 和自动装配例外另见 [基线报告](PHASE0_BASELINE.md)。
