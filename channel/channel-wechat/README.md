# WeChat 渠道适配

本模块是微信支付独立适配边界，业务契约依赖 channel-api，并复用 loadup HTTP/KMS 等技术组件；不依赖 payment。

后续在本模块实现 ChannelProvider 与自身的条件自动装配，覆盖付款码、JSAPI/H5、直连/服务商、商户/子商户，以及查询、关闭、退款与回调。协议实现应复用 loadup HTTP/KMS 组件，按原绑定核验实际收款账户、响应签名和金额。

当前已有 APIv3 的凭证读取、请求签名和响应验签基础源码，尚无支付适配器或已注册 Provider。上游请求 WECHAT 时，统一 Facade 明确拒绝未实现能力，不转发到其他渠道，不生成模拟资金结果。该模块当前随 payment 业务装配打包，不是独立应用。协议基础源码未编译、未测试、未进行真实渠道验收。
